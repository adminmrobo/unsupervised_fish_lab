# 비지도학습 물고기 연구실 — 이미지 제작 명세서

## 1. 그림체와 고정 외형

- 그림체: 16비트 RPG풍 픽셀아트 (굵은 어두운 외곽선, 2~3단계 명암, 작은 반사광). 캐릭터 팩 `CHAR_lab4` 18-3을 따릅니다.
- 장면 조명: 낮의 연구실·낮의 어시장. 흰 벽, 큰 창의 자연광, 연보라·민트·분홍 소품. 밤·어둠·네온은 쓰지 않습니다.
- 고정 외형: 캐릭터 팩 18-4 (박사·조수·초파리 연구원·주판봇 v2). 인턴 시아·모아는 본문 말풍선에만 나오고 표지에는 넣지 않습니다.
- 그림 안 글자·숫자·로고 금지. 주판봇은 Money-Robo의 특징(흰 둥근 머리, 노란 눈, 금화)을 쓰지 않습니다.

## 3. 새로 그릴 그림 상세

표지 6장의 장소·주제 은유·포즈·대체 글·영어 프롬프트는 `COVER_PROMPTS_unsupervised_fish_lab.md`에 있습니다. 표지끼리 장소와 소품이 겹치지 않게 정했습니다.

| 키 | 장소 | 주제 은유 |
|---|---|---|
| cover_00 | 어시장 입구 | 이름표를 뒤집어 덮은 물고기 상자 |
| cover_01 | 연구실 실험대 | 두 물고기 사이의 빛나는 점선, 같은 눈금의 자 |
| cover_02 | 어시장 진열대 | 체형별로 나뉜 세 주머니와 깃발(중심) |
| cover_03 | 연구실 바닥과 흰 벽 | 손전등 그림자(투영)와 바닥의 종이 지도 |
| cover_04 | 검수 카운터 | 천으로 가린 저울, 좁은 입구의 상자, 경보등 |
| cover_05 | 어시장 운영실 | 초록·파랑 손잡이 조작판, 검수 아치 |

## 4. 일관성 지침

- cover_00을 먼저 받아 그림체를 확인하고, 나머지 다섯 장은 cover_00을 참고 그림으로 함께 올립니다.
- 표지는 대결 전 장면입니다. 누가 이길지 드러나는 표정을 쓰지 않습니다.
- 초파리는 왼쪽에서 오른쪽을, 주판봇은 오른쪽에서 왼쪽을 봅니다. 박사·조수는 좌우를 뒤집지 않습니다.
- 생물 앵커가 아닌 시리즈라 현미경·해부 소품을 넣지 않습니다.

## 5. 넘겨받은 뒤 처리

1. 그림체가 픽셀아트인지, 16:9인지, 글자가 없는지, 네 캐릭터가 모두 기준 외형인지 확인합니다.
2. `img/cover_NN.webp` (1600×900, 220 KB 이하)로 저장합니다. 원본 PNG는 `img/src/`에 둡니다.
3. `thumb_NN.webp`(3:2)와 `og_NN.webp`(1200×630)를 잘라 만듭니다.
4. 페이지는 다시 만들 필요가 없습니다. 파일이 있으면 대체 표지 대신 그림을 보여 줍니다.
5. `cover_manifest.json`의 해당 항목 `status`를 `ok`로 바꿉니다.
