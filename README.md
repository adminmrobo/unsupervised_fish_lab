# 비지도학습 물고기 연구실 — 라벨링 없이 맞추는 AI (unsupervised_fish_lab)

> 정답표가 없어도, 데이터 안에 숨은 모양을 찾아낼 수 있을까?

어시장에서 잰 물고기 1,554마리의 **종 이름표를 덮고**, 측정값 여섯 개(무게·길이 세 가지·높이·폭)만으로 비지도학습을 기초부터 배우는 연구실 해설 시리즈입니다. 박사·조수 하루·초파리 연구원·주판봇이 진행하고, 인턴 모아가 장마다 「지도학습 노트」로 앞 시리즈(같은 물고기로 종을 맞힌 지도학습)와 지금 배우는 것을 나란히 보여 줍니다. 모든 그래프와 표는 페이지 안에서 실제 데이터로 직접 계산합니다.

- 저장소: https://github.com/adminmrobo/unsupervised_fish_lab

- 분야: 인공지능 (비지도학습 · 군집화 · 차원 축소 · 자기지도학습)

## 핵심 숫자 (code/analysis.py 재현)

| 무엇 | 값 |
|---|---|
| 가장 가까운 이웃이 같은 종인 비율 (원 단위 → 표준화) | 78.9% → 92.3% |
| 체형 비율 k-평균 k=3 실루엣 / 이름표 대조 점수(ARI) | 0.680 / 0.609 (원 단위 6개로 나누면 ARI 0.109) |
| PCA 설명된 분산 PC1 / PC1+PC2 | 87.6% / 96.1% |
| 가린 무게 맞히기 시험 평균 빗나감 (평균으로 찍으면) | 48.7g (318.8g) |
| 시험 복원 오차 오토인코더 6-16-2-16-6 / PCA 두 축 | 0.0102 / 0.0581 |
| 이름표 없이 그린 지도 위 이웃 5마리 정답률 (이름표 7장만이면) | 83.1% (45.9%) |
| 지도학습 비교: KNN(이웃 1) / 로지스틱 회귀, 물고기 단위 5겹 교차검증 | 92.0% / 89.8% |

## 원자료와 다르게 적은 곳

- 원자료 슬라이드의 PC1 설명된 분산 87.8%를 같은 데이터로 다시 계산한 **87.6%**로 바꿨습니다(3장 3-3).
- 원자료의 "물고기 데이터처럼 대개 직선으로 접히면 PCA면 충분하다"를, 다시 계산한 결과(오토인코더 복원 오차가 PCA의 약 1/6)에 맞춰 **"무게처럼 휜 관계가 있으면 곡선 접기(오토인코더)가 복원에 유리하다"**로 바꿨습니다(4장 4-2).
- 원자료의 "무대"(군집)를 이 시리즈에서는 **"주머니"**라고 부릅니다.
- 원자료의 얼굴 사진 예(고유 얼굴, 정면·옆모습)는 그림 없이 말로만 설명하고, 같은 원리를 물고기 지도와 "배운 범위 밖" 경보로 옮겼습니다.

## 데이터

원 자료는 Kaggle "Fish market"(Aung Pyae, 물고기 7종 159마리)입니다. 지도학습 시리즈에서 종별 평균·분산을 지키며 정규분포로 늘린 1,590행을 만들었고, 무게 0인 1행과 똑같은 35행을 빼 1,554마리를 씁니다. 같은 원본에서 늘린 물고기는 같은 `seed_id`를 가지며, 학습·시험을 나눌 때는 이 묶음을 갈라 놓지 않습니다.

import pandas as pd
url = 'https://raw.githubusercontent.com/adminmrobo/unsupervised_fish_lab/main/data/fish_market_x10.csv'
df = pd.read_csv(url)
df = df[df['weight_g'] > 0].drop_duplicates().reset_index(drop=True)   # (1554, 9)

## 숫자 표시 원칙

- "실제 데이터"로 표시한 그래프는 1,554마리를 그대로 그렸습니다. "scikit-learn 값"은 `code/analysis.py`의 결과이고, 나머지 실험은 페이지가 브라우저에서 직접 계산합니다(k-평균 시작점 방식 차이로 소수 셋째 자리가 다를 수 있음).
- 종 이름표는 학습에 쓰지 않고, 채점·대조에만 씁니다.
- 실전 연습장의 측정 오차, 이상 물고기, 검수 시간은 설명용 예시값입니다. 교육용이며 경영·투자 권고가 아닙니다.
